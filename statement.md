# Problem Statement
Educational institutes struggle to manage student records, course
catalogs, and enrollment data without expensive software.

# Scope
A console-based CLI application for a single institute to manage
student, course, enrollment, and grade data.

# Target Users
- Academic administrators
- Registrars
- Faculty managing grades

# High-Level Features
1. Student record management
2. Course catalog management
3. Enrollment & grade tracking
4. Data backup & reports
